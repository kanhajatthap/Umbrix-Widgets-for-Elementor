# ElementStack – Elementor Widgets

ElementStack is a collection of powerful and lightweight custom widgets for the Elementor Page Builder.  
It helps you build modern and responsive layouts in WordPress with ease.

## Features

- Custom Elementor widgets
- Lightweight and fast performance
- Easy to use interface
- Fully responsive design
- Clean and developer-friendly code
- Regular updates

## Requirements

- WordPress 5.8 or higher
- Elementor 3.0 or higher
- PHP 7.4 or higher

## Installation

1. Download or clone this repository.
2. Upload the plugin folder to the `/wp-content/plugins/` directory.
3. Go to **WordPress Admin → Plugins**.
4. Activate **ElementStack – Elementor Widgets**.

## Usage

1. Open any page with **Elementor**.
2. Search for **ElementStack** widgets in the Elementor panel.
3. Drag and drop the widgets into your layout.
4. Customize the settings as needed.

## Plugin Settings

ElementStack adds a settings page under the WordPress admin menu where you can enable or disable individual widgets. This makes it easy to keep your Elementor panel clean and only show the widgets you need.
