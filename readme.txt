== Description ==

ElementsKey Addons for Elementor adds 73 powerful, lightweight widgets to the Elementor page builder, plus a Theme Builder module for custom headers, footers and archive templates.

All widgets are built natively for Elementor and include Elementor style controls for colors, spacing, typography and hover states where applicable.

**Key features:**

* 73 Elementor widgets - Loop Grid, Loop Carousel, Data Table, Progress Bar, Feature Comparison Table, Portfolio, Tabs, Accordion, Countdown, Pricing Tables and many more
* Widget Manager - enable or disable any widget from one settings screen
* Theme Builder module - custom header, footer, archive and 404 templates
* Loop Grid with "Load on Demand" / infinite scroll support
* Fully responsive and lightweight
* Works with any Elementor theme

**Featured widgets:**

* **Loop Grid / Loop Carousel** - dynamic post grids and carousels from any post type with full query controls
* **Data Table** - label-value rows with titled card and alternating backgrounds
* **Progress Bar / Progress Tracker** - animated progress with label and percentage
* **Feature Comparison Table** - feature vs checkmark comparison
* **Share It** - share buttons with copy-link support
* **Off-Canvas** - slide-in panel with toggle and overlay
* **Theme Builder** - headers, footers, archives and 404s

= Requirements =

* WordPress 6.0 or higher
* Elementor (free) installed and activated

= Installation =

1. Upload the `elementskey` folder to the `/wp-content/plugins/` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the "Plugins" screen in WordPress.
3. Go to the new "ElementsKey" menu in the admin sidebar to manage which widgets are enabled.
4. Open any page in the Elementor editor - the widgets appear under the "ElementsKey Elements" category.

== Frequently Asked Questions ==

= Does this require Elementor Pro? =

No. ElementsKey works with the free version of Elementor.

= Can I disable widgets I don't use? =

Yes. Go to the ElementsKey settings page and toggle any widget on or off.

= Is it compatible with any theme? =

Yes, the widgets work with any WordPress theme that supports Elementor.
